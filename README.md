# ⚡ Control D Manager (PWA)

A lightweight, mobile-first Progressive Web App (PWA) for managing your [Control D](https://controld.com) DNS subscription on the go. Built as a single zero-dependency HTML file, it runs entirely in your browser and communicates directly with the Control D API.

---

### ✨ Features

* **📱 Mobile-First PWA:** Native-feeling UI with dark mode, bottom navigation, and sheet drawers. Installable on iOS and Android home screens.
* **📊 Analytics to Rules Engine:** Tap any top-requested domain in your aggregated stats to instantly convert it into a Custom Rule (Block, Bypass, or Redirect) and route it to specific Rule Folders.
* **📁 Profile & Folder Management:** Create, organize, and manage Rule Folders and custom rules across all your profiles.
* **📱 Endpoint Monitoring:** Inspect active devices, enforce profiles, and monitor connectivity status.
* **🔐 Transportable Session Security:** Stored locally in your browser (`localStorage` / `sessionStorage`). Your API key is never transmitted to any third-party server or backend. Includes portable token export/import for easy setup across devices.

---

### 🚀 Getting Started

1. Open `index.html` locally in any modern browser, or host it via **GitHub Pages** / **Cloudflare Pages**.
2. Click **🔑 API Key** in the top right header.
3. Paste your Control D Bearer Token / API Key from your account dashboard and tap **Save**.
